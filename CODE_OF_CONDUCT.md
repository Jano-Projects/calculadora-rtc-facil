# Código de conduta

Este é um projeto aberto, feito para ajudar pessoas a entender a reforma tributária. Quem participa (em issues, pull requests ou qualquer outro espaço do projeto) se compromete a:

- tratar todos com respeito, sem ofensas, ataques pessoais, assédio ou discriminação de qualquer tipo;
- discutir ideias e código, não pessoas, aceitando críticas construtivas e explicando as suas;
- lembrar que muita gente aqui não é da área tributária nem de tecnologia, e responder com paciência;
- não publicar dados pessoais ou fiscais de terceiros (CNPJ, CPF, notas fiscais reais, endereços) sem autorização;
- não usar o projeto para propaganda, spam ou promessas de resultado tributário.

## Quando algo der errado

Avise quem mantém o projeto pelo canal privado da [política de segurança](SECURITY.md) ("Reportar uma vulnerabilidade"), mesmo que não seja um problema técnico. A mensagem fica visível só para quem mantém o projeto.

Comentários, issues ou contribuições que desrespeitem este código podem ser editados, ocultados ou removidos. Quem insistir pode ser bloqueado no projeto.

Este código se inspira no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), versão 2.1.
